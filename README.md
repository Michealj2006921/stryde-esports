# STRYDE — Play. Compete. Rise.

STRYDE is a mobile-first esports competition frontend prototype built with plain HTML, CSS, and JavaScript.

## Included
- Responsive landing page and mobile bottom navigation
- Featured match cards for Blood Strike, Call of Duty: Mobile, and PUBG Mobile
- Match category filters and search
- Informational match and sign-in modals
- Tournament promotion and community feature sections
- Dark violet design system with Exo 2 and Inter typography

## Run locally
Open `index.html` in a modern browser. For a local server, use VS Code Live Server or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Important status
This is **frontend-only**. Match counts, schedules, prize pools, and player statistics are sample UI content. Sign-in, matchmaking, tournament registration, wallets, payments, rankings, and admin tools are not connected to a backend. Do not use this preview to collect real user or payment information.
